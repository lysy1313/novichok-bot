# 🤖 СпортТовары: Цифровой напарник новичка (Telegram Bot)

Мобильный Telegram-бот для адаптации линейного персонала розничной сети и склада (кладовщики, комплектовщики, продавцы, кассиры).  
Работает в связке с HR-дашбордом и облачной базой данных Supabase.

🔗 **Запуск бота:** [@sport_onboarding_test_bot](https://t.me/sport_onboarding_test_bot)  
📊 **HR-дашборд:** [Ссылка на Vercel](https://novichok-dashboard.vercel.app/)

---

## 🎯 Назначение бота

Кладовщик на смене или продавец в торговом зале не имеют постоянного доступа к ПК и корпоративному Битрикс24. Бот в кармане смартфона решает 3 задачи:

1. **Быстрая ориентация:** Памятка первого дня (где раздевалка, обед, кому сдать сканер ТСД).
2. **Чек-лист задач от наставника:** Новичок в один клик отмечает выполненные пункты смены.
3. **Безопасная обратная связь:** 15-секундный вечерний пульс-опрос о бытовых фактах дня и кнопка SOS для экстренной связи с наставником.

---

## ⚙️ Функционал бота

- **👤 Выбор профиля:** Автоматическая привязка `telegram_id` проверяющего/сотрудника к базе кадров.
- **📝 Задачи на смену:** Интерактивный список задач, назначенных руководством из дашборда (кнопки-чекбоксы `[ ]` / `[x]`).
- **📊 Пульс дня (3 вопроса по фактам смены):**
  1. _Обед:_ Успел ли нормально отдохнуть и пообедать?
  2. _Наставник:_ Помог ли наставник при трудностях в работе?
  3. _Задачи:_ Понятен ли фронт работ на завтра?
- **💬 Текстовый комментарий:** Возможность описать проблему своими словами текстом — комментарий мгновенно отображается в дашборде HR.
- **🆘 Экстренная кнопка SOS:** Моментальный алерт руководству при конфликте или непонимании обязанностей.

---

## 🏗 Архитектура проекта

Код декомпозирован на независимые модули:

- `config.py` — переменные окружения и заголовки авторизации Supabase.
- `db.py` — слой взаимодействия с базой данных (PostgREST API).
- `keyboards.py` — фабрика интерактивных инлайн-клавиатур.
- `bot.py` — точка входа, обработчики команд и бесконечный цикл опроса (`polling`).

---

## 🛠 Стек технологий

- **Язык:** Python 3.11+
- **Библиотека:** `pyTelegramBotAPI` (telebot)
- **Сетевой клиент:** `requests` (легковесное прямое взаимодействие с REST API без тяжелых C++ зависимостей)
- **Хостинг:** Railway.app (работает 24/7 в облачном контейнере)

## 💻 Локальный запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/lysy1313/novichok-bot.git
cd novichok-bot

# 2. Создать и активировать виртуальное окружение
python -m venv venv
source venv/bin/activate  # на Windows: venv\Scripts\activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Настроить файл .env
BOT_TOKEN=your_telegram_bot_token
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_anon_key

# 5. Запустить бота
python bot.py
```
